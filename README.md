# Site — Dra. Isadora Inácio Ribeiro

Protótipo de apresentação do site da Dra. Isadora Inácio Ribeiro, cirurgiã-dentista em Sarzedo • MG (CRO-MG 80.424).

- Dente em fio de ouro em 3D (Three.js) guiado pelo scroll
- Comparador de antes e depois
- Layout responsivo, fundo branco com marsala e dourado da marca

Endereço, horários e WhatsApp ainda estão marcados como "a confirmar".

Para ver localmente, abra a pasta com um servidor simples (ex.: `python3 -m http.server`) e acesse `http://localhost:8000`.
